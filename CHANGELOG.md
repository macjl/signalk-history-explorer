# Changelog

## 0.2.12 - 2026-09-25

- Enable the plugin automatically after installation when it has no existing enable/disable setting.
- Show the effective History API provider in the period bar and direct context, path, and value queries to it.

## 0.2.11 - 2026-09-25

- Explore paths recorded by a Signal K History API provider over a selected time range.
- Select a vessel context or ALL, filter paths, and expand them to load values lazily.
- View numeric history as a chart and table, and text or state history as a table.
- Show context, source, and unit for each value when provided by the History API.
